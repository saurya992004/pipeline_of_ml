QUESTION 1 - AIOps Log Anomaly Detection
============================================================

QUESTION REQUIREMENTS
---------------------
Create or read a sample dataset containing:
1. Timestamp
2. CPU Usage
3. Memory Usage
4. Response Time

Then:
1. Calculate basic statistics.
2. Detect anomalous values using a simple threshold-based approach.
3. Print anomalous records.
4. Display a graph showing metric values and anomalies.

Expected sample pattern:
Total records: 20
Anomalies detected: 3

Sample anomaly format:
10:05  95%  ANOMALY
10:12  97%  ANOMALY
10:18  92%  ANOMALY


MINIMAL CODE - IF DATA IS ALREADY IN A CSV FILE
------------------------------------------------

import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("data/server_logs.csv")

print("===== Basic Statistics =====")
print(df[["CPU", "Memory", "Response_Time"]].describe())

threshold = 80

df["Status"] = "NORMAL"
df.loc[df["CPU"] > threshold, "Status"] = "ANOMALY"

anomalies = df[df["Status"] == "ANOMALY"]

print("\n===== Anomalies =====")
print(anomalies[["Timestamp", "CPU", "Status"]])

print("\nTotal records:", len(df))
print("Anomalies detected:", len(anomalies))

plt.plot(df["Timestamp"], df["CPU"], marker="o", label="CPU")
plt.scatter(
    anomalies["Timestamp"],
    anomalies["CPU"],
    marker="x",
    s=100,
    label="Anomaly"
)

plt.axhline(threshold, linestyle="--", label="Threshold")
plt.xlabel("Timestamp")
plt.ylabel("CPU Usage (%)")
plt.title("AIOps CPU Anomaly Detection")
plt.xticks(rotation=45)
plt.legend()
plt.tight_layout()
plt.show()

QUESTION 3 - Python Kafka Consumer
============================================================

QUESTION REQUIREMENTS
---------------------
Write a Python Kafka consumer that:
1. Connects to the Kafka broker.
2. Subscribes to the server_metrics topic.
3. Continuously receives messages.
4. Displays the received server metrics.
5. Detects whether CPU usage is greater than 80%.
6. Prints:
   ALERT: High CPU detected on server01

Example:
Received:
Server: server01
CPU: 85%
Memory: 62%
ALERT: High CPU detected on server01


MINIMAL CODE
------------

from kafka import KafkaConsumer
import json

consumer = KafkaConsumer(
    "server_metrics",
    bootstrap_servers="localhost:9092",
    value_deserializer=lambda x: json.loads(x.decode("utf-8"))
)

for message in consumer:
    data = message.value

    server_id = data["server_id"]
    cpu = data["cpu_usage"]
    memory = data["memory_usage"]

    print("Received:")
    print("Server:", server_id)
    print("CPU:", str(cpu) + "%")
    print("Memory:", str(memory) + "%")

    if cpu > 80:
        print("ALERT: High CPU detected on", server_id)
    else:
        print("Normal")

    print()

QUESTION 4 - Build an AIOps Workflow Using Airflow
============================================================

QUESTION REQUIREMENTS
---------------------
Create an Apache Airflow DAG with these tasks in this exact order:

collect_metrics
        |
        v
process_metrics
        |
        v
detect_anomaly
        |
        v
generate_report

Task 1 - collect_metrics
Generate/sample:
CPU = 87
Memory = 65
Response Time = 420ms

Task 2 - process_metrics
Process the collected metrics and print them.

Task 3 - detect_anomaly
Check:
CPU > 80

If yes:
Anomaly detected: High CPU usage

Otherwise:
No anomaly detected

Task 4 - generate_report
Print:

===== AIOps Report =====
Metrics collected successfully
Metrics processed successfully
Anomaly detection completed
========================

DAG must:
- Use PythonOperator.
- Define all four tasks.
- Define correct dependencies.
- Run in this order:
  collect_metrics >> process_metrics >> detect_anomaly >> generate_report


MINIMAL CODE
------------

from airflow import DAG
from airflow.operators.python import PythonOperator
from datetime import datetime


def collect_metrics():
    print("CPU = 87")
    print("Memory = 65")
    print("Response Time = 420ms")


def process_metrics():
    print("Metrics processed successfully")


def detect_anomaly():
    cpu = 87

    if cpu > 80:
        print("Anomaly detected: High CPU usage")
    else:
        print("No anomaly detected")


def generate_report():
    print("===== AIOps Report =====")
    print("Metrics collected successfully")
    print("Metrics processed successfully")
    print("Anomaly detection completed")
    print("========================")


with DAG(
    "aiops_workflow",
    start_date=datetime(2026, 1, 1),
    schedule=None,
    catchup=False
) as dag:

    t1 = PythonOperator(
        task_id="collect_metrics",
        python_callable=collect_metrics
    )

    t2 = PythonOperator(
        task_id="process_metrics",
        python_callable=process_metrics
    )

    t3 = PythonOperator(
        task_id="detect_anomaly",
        python_callable=detect_anomaly
    )

    t4 = PythonOperator(
        task_id="generate_report",
        python_callable=generate_report
    )

    t1 >> t2 >> t3 >> t4


IMPORTANT AIRFLOW LINE
----------------------
t1 >> t2 >> t3 >> t4

This creates the exact required dependency/order.

QUESTION 5 - Integrated AIOps Challenge
============================================================

QUESTION REQUIREMENTS
---------------------
Modify the Kafka consumer so that it:
1. Receives server metrics from Kafka.
2. Checks CPU usage.
3. Detects an anomaly when CPU > 80%.
4. Prints an alert.
5. Maintains a count of detected anomalies.

Example:

Message received: server01 | CPU: 85%
ALERT: High CPU detected

Message received: server02 | CPU: 45%
Normal

Message received: server03 | CPU: 91%
ALERT: High CPU detected

Total anomalies detected: 2


MINIMAL CODE
------------

from kafka import KafkaConsumer
import json

consumer = KafkaConsumer(
    "server_metrics",
    bootstrap_servers="localhost:9092",
    value_deserializer=lambda x: json.loads(x.decode("utf-8"))
)

anomaly_count = 0

for message in consumer:
    data = message.value

    server = data["server_id"]
    cpu = data["cpu_usage"]

    print("Message received:", server, "| CPU:", str(cpu) + "%")

    if cpu > 80:
        print("ALERT: High CPU detected")
        anomaly_count += 1
    else:
        print("Normal")

    print("Total anomalies detected:", anomaly_count)
